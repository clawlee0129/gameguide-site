## 欢迎来到提瓦特

《原神》是 miHoYo 开发的开放世界动作 RPG，截至2026年已更新至6.x版本，拥有超过80名可玩角色和7个已开放国家。如果你是纯新手，这份指南将帮你避开所有常见陷阱。

---

## 冒险等级系统

冒险等级（AR）是你的总体进度指标，1-60级。所有内容都由 AR 解锁：

| AR 范围 | 解锁内容 |
|---------|--------|
| 1-15 | 蒙德主线、基础系统 |
| 16 | 可联机合作 |
| 20 | 螺旋深渊、尘歌壶（家园系统） |
| 25 | 世界等级2（提升敌人等级和掉落） |
| 30 | 大部分主线完成后可专注刷圣遗物 |
| 45 | 圣遗物最高等级副本，开始刷终局装备 |
| 55+ | 终局——角色满级、深渊满星、等待新版本 |

**关键建议**：在 AR45 之前不要用脆弱树脂（体力恢复道具）。AR45 后圣遗物副本最高掉落率才值得消耗。

## 原石经济系统

### 来源
| 来源 | 每版本大约获得 |
|--------|------------------------|
| 每日委托 | 60原石/天 = 3,780/版本 |
| 螺旋深渊满星 | 1,200/周期 |
| 版本活动 | 约2,000-3,000 |
| 探索（宝箱、神瞳、成就） | 约3,000-5,000（新区域时） |
| 月卡（空月祝福） | 300创世结晶 + 90原石/天 |
| 战斗通行证（珍珠纪行） | 680原石 + 大量培养材料 |

每版本无氪约可获取 50-70 抽。月卡+纪行约 80-100 抽。

### 卡池机制
- **角色活动**：90抽小保底（50%当期），180抽大保底（100%当期）
- **武器活动**：80抽小保底，约210抽满定轨
- **常驻池**：仅用免费蓝球抽，永远不要花原石

**黄金法则**：**永远不要在无大保底的情况下下池**。160抽=一名确定角色。没到达这个数字就别碰心愿按钮。

## 核心战斗系统

### 元素反应

这是原神战斗的灵魂。两种元素相互作用的反应：

| 反应 | 公式 | 伤害类型 |
|--------|------|-------------|
| 蒸发 | 水+火（1.5x/2x 倍率） | 增幅反应 |
| 融化 | 火+冰（1.5x/2x 倍率） | 增幅反应 |
| 感电 | 水+雷（持续雷伤+打断） | 剧变 |
| 超导 | 冰+雷（范围冰伤-40%物抗） | 剧变 |
| 超载 | 火+雷（范围火伤+击飞） | 剧变 |
| 扩散 | 风+任意（范围元素传播） | 翠绿4件套核心 |
| 绽放 | 水+草（生成草原核） | 种门 |
| 超绽放 | 草原核+雷（追踪弹） | 种门 |
| 烈绽放 | 草原核+火（范围爆炸） | 种门 |
| 激化 | 草+雷（附加基础伤害） | 增幅剧变混合 |

### 配队基础

标准4人小队需要：
1. **主C**（站场输出）
2. **副C**（脱手输出/元素附着）
3. **辅助/增伤**（扩散减抗、攻击力增幅）
4. **生存位**（治疗/护盾）

例如胡桃双水队：胡桃(主C)+夜兰(副C+水附着)+钟离(盾)+行秋(额外水+减伤)

## AR 1-45 升级路线

### 前30级
- 推进主线魔神任务（Archon Quest）
- 开启所有传送点
- 收集神瞳并供奉七天神像（提升体力上限）
- 每天完成4个每日委托
- 不要浪费资源随意培养角色——专注4-6个核心角色

### 30-45
- 解锁所有周本Boss（风魔龙、北风狼、黄金屋等）
- 开始刷角色天赋和武器突破材料
- AR40-45开始存圣遗物狗粮（日后强化素材）
- 完成传说任务获取原石和角色故事

## 最重要的一条建议

**不要追逐强度膨胀**。每个国家的版本更新都会推出更强角色，但原神本质是休闲探索游戏。深渊满星每月仅差600原石（不到4抽）。抽你喜欢的角色，而不是"当前版本最强"。享受探索和音乐，这才是原神的核心体验。
