## 配队核心思路

原神队伍分为三种战斗类型：
1. **增幅反应队**（蒸发/融化）：元素倍率2x，伤害天花板
2. **剧变反应队**（激化/绽放）：固定伤害+反应共存
3. **纯色队**：无视反应，靠专属增伤机制

每一队需要满足：充能循环、生存保障和元素附着。

## S级：深渊通关首选

### 那维莱特双水队
```
那维莱特(主C) + 芙宁娜(增伤) + 枫原万叶(减抗聚怪) + 钟离/白术(盾奶)
```
- **原理**：那维莱特蓄力重击AoE穿盾；芙宁娜全队增伤；万叶翠绿40%减抗
- **优势**：不依赖反应，无障碍输出，那维莱特1命后霸体无缝
- **缺点**：需要三个限定五星。替代：钟离→莱依拉，万叶→砂糖

### 胡桃双水蒸发队
```
胡桃(主C) + 夜兰(副C+水附着) + 行秋(水附着+减伤) + 钟离(盾)
```
- **原理**：双水高频附着让胡桃每次重击触发1.5x/2x蒸发
- **伤害天花板**：胡桃Q+E+重击跳→约100万/轮
- **关键**：胡桃半血被动(33%火伤加成)，钟离盾防猝死

### 刻晴/菲谢尔激化队
```
刻晴(主C) + 菲谢尔(副C) + 纳西坦(草元素) + 钟离/久岐忍(生存)
```
- **原理**：草+雷触发原激化→刻晴和菲谢尔每次攻击附加基础伤害（与攻击力暴击爆伤独立乘算）
- **优势**：刻晴在激化体系翻身为有效主C，菲谢尔A4被动高频触发
- **关键**：纳西坦大招给站场角色+250精通

## A级：高效但条件苛刻

### 雷神国家队
```
雷电将军(充能+主C) + 行秋(水附着) + 香菱(火副C) + 班尼特(攻击+回血)
```
- **性价比**：仅需1个限定五星（雷神），其余全为四星老牌
- **循环**：雷神E→班尼特Q→行秋Q→香菱Q→雷神Q砍满
- **要求**：雷神充能270%+、香菱充能200%+
- **伤害**：约60-80万/轮

### 艾尔海森超激绽队
```
艾尔海森(主C) + 夜兰/行秋(水) + 久岐忍(雷+治疗) + 纳西坦(草)
```
- **原理**：草水生成草原核→久岐忍雷环触发超绽放追踪弹→艾尔海森站场剑雨
- **优势**：超绽放伤害不依赖攻击力——久岐忍只需堆精通
- **低成本**：两个限定五星（艾尔海森、纳西坦），久岐忍为四星

### 甘雨融化队
```
甘雨(主C) + 香菱/迪希雅(火) + 班尼特(攻击) + 钟离(盾)
```
- **原理**：甘雨蓄力二段引爆火附着，2x融化倍率
- **伤害**：每箭约8-15万（蓄力+融化双加成）
- **手残党慎入**：被摸即倒——必须有盾

## B级：专属配队

### 一斗纯岩队
```
荒泷一斗(主C) + 五郎(岩专属辅) + 阿贝多(后台岩输出) + 钟离(盾+减抗)
```
- **原理**：岩系不反应，堆攻击+防御转伤
- **五郎**：三岩以上队伍提升25%防御+40%暴伤
- **弱点**：对元素盾破盾困难（如深渊法师的元素盾）

### 妮露绽放队
```
妮露(触发) + 纳西坦(草) + 行秋/夜兰(水) + 瑶瑶/白术(奶)
```
- **原理**：妮露被动将草原核变为丰穰之核，大幅提升绽放伤害且立即爆炸
- **限制**：队伍只允许水+草角色——无法带风系聚怪
- **对群无敌**：大范围持续伤害，怪越多越猛

## C级：趣味配队

### 物理队：优菈超导
```
优菈(物C) + 雷神(超导触发) + 罗莎莉亚(暴击率) + 钟离(盾+物理减抗)
```
物理队版本边缘，但优菈Q的核弹特效仍然是最华丽的。

### 蒸发香菱
```
香菱(核心) + 行秋(水) + 班尼特(攻击) + 任意(钟离/万叶/雷神)
```
只要有这三个四星，就能深渊满星。原神真核不是五星而是四星。
