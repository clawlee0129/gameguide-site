## 元素反应深度解析

元素反应的伤害并非简单的公式计算——它由**角色等级**、**元素精通**和**抗性**共同决定，部分反应还吃**攻击力/暴击/爆伤**。

### 增幅反应（蒸发/融化）
- 基础公式：最终伤害 = 基础伤害 × 反应倍率 × (1 + 元素精通加成 + 反应加成%)
- 反应倍率：火打水2x（蒸发）、水打火1.5x（蒸发）、火打冰2x（融化）、冰打火1.5x（融化）
- 暴击爆伤在此之上正常计算

**实战**：胡桃重击打水附着2x蒸发，每跳10万变20万。所以胡桃配双水队。

### 剧变反应（超载/感电/超导/扩散/绽放/超绽放/烈绽放）
- 基础公式：最终伤害 = 基础剧变伤害 × (1 + 元素精通加成 + 反应加成%) × 抗性减伤
- 基础剧变伤害仅基于角色等级和反应类型
- **不享受攻击力/暴击/爆伤**

**剧变基础伤害表（90级角色）**：
| 反应 | 基础伤害 |
|------|------|
| 超载 | 约3,800 |
| 感电 | 约2,800×2 |
| 超导 | 约1,200 |
| 扩散 | 约1,500 |
| 绽放 | 约3,200 |
| 超绽放 | 约6,400 |
| 烈绽放 | 约6,400 |

这就是为什么久岐忍堆精通到1,000后超绽放每颗种子炸35,000——比许多角色普攻还高。

## 元素附着理论

每个攻击技能都有独立的元素附着冷却（Internal Cooldown，ICD），通常为：
- **标准ICD**：同一敌人每3次攻击或每2.5秒施加一次元素附着
- **无ICD**：每次攻击都附着元素（极少见）
- **特殊ICD**：角色专属机制（如那维莱特重击每次判定都可附着）

**实战意义**：
- 行秋大招有极短ICD——每秒约1-2次水附着，完美压制火附着
- 香菱旋火轮ICD较短——每次转圈可附着火
- 攻击频率高但ICD长的角色不适合担任附着位（如刻晴普攻）

## 伤害乘区理论

最终伤害是六个乘区的乘积：
1. **基础攻击力**（角色白值+武器）
2. **攻击力加成%**（圣遗物+武器副属性+各类Buff）
3. **增伤%**（元素伤害、普攻增伤、各类条件增伤）
4. **暴击×暴伤**
5. **反应倍率**（增幅反应2x/1.5x，或激化基础伤害）
6. **敌人抗性减伤**（翠绿套40%减抗、钟离盾20%减抗等）

**核心原则**：每个乘区均衡投资，不要全堆一个区。例如70/140双暴时继续堆暴伤不如去堆精通（反应队）或攻击力。

## 元素抗性与减抗

敌人默认抗性为10%（物理约20-30%）。抗性公式：
- 抗性>75%时：伤害 = 1/(1+4×抗性)
- 0%<抗性<75%时：伤害 = 1-抗性
- 抗性<0%时：伤害 = 1-抗性/2（负抗性收益减半）

**减抗来源**：
- 翠绿4件套：扩散对应元素-40%抗性
- 钟离盾：附近敌人全属性-20%抗性
- 深林4件套：草系角色命中-30%草抗

理论极限减抗可将0%抗敌人降至-30%（翠绿+钟离叠加），提升约15%最终伤害。

## 防御力与等级压制

敌人防御力 = 500 + 5×等级。角色对同级敌人有约50%伤害减免（来自防御）。**角色等级低于敌人时**会额外承受约3%每级的伤害降低。

所以深渊12层的95级敌人对80级角色有更大减伤——将主C升到90级在深境螺旋中是有效的（不像野外世界不明显）。

## 终局输出手法

### 雷神国家队标准循环
1. 雷神E（触发协同攻击）
2. 班尼特Q（攻击力Buff）
3. 行秋Q→E→E（祭礼剑双E）
4. 香菱Q→E
5. 雷神Q→砍满7秒
6. 循环

### 那维莱特单通流程
1. E→立刻重击开始蓄力
2. 重击持续输出约3秒
3. 吸收三个源水之滴（减少蓄力时间）
4. 再次重击→吸收→Q（获得更多水滴）
5. 循环重击吸收
