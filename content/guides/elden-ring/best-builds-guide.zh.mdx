## 构筑哲学

艾尔登法环的构筑并非仅仅关乎属性分配——而是**武器、护符、灵药、大卢恩和战灰的协同作用**。一个好的构筑将所有部件整合成一个统一的目标。本指南中的每个构筑都已使用+10/+25武器测试，可携带你完成新游戏并进入新游戏+。

## 核心机制复习

### 负重阈值
- **轻翻滚**（<30%负重）：额外距离和无敌帧。专家级构筑偏好。
- **中翻滚**（30-69.9%负重）：标准无敌帧。大多数构筑在此操作。
- **重翻滚**（70-99.9%负重）：降低无敌帧，缓慢恢复。**永远不要运行此状态**。
- **超重**（>100%负重）：无法翻滚。直接死亡。

### 武器补正等级
E（最差）→ D → C → B → A → S（最佳）。不同亲和质变可改变补正等级。一把厚重质变+25巨剑力量S补正远超一把标准+25巨剑的B补正。

## 1. 纯力量——巨剑猛男

### 概述
最简单的构筑：获取最大可能的力量、最重的护甲和最沉甸甸的打击武器。没有花哨法术，只有纯粹的物理优势。

### 装备
- **右手1**：巨剑+25（厚重质变，狮子斩战灰）
- **右手2**：巨锤+25（祈祷一击战灰用于治疗）
- **左手1**：黄铜盾+25（无战技或黄金格挡）
- **护甲**：莱恩尼尔套装（保持中负重，调整耐力）
- **护符**：龙徽大盾护符、亚历山大碎片、绿龟护符、大壶众武护符

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 60 |
| 集中力 | 9（基础） |
| 耐力 | 40 |
| 力量 | 80（双手持达到120） |
| 敏捷 | 13（基础需求） |
| 智力 | 7（基础） |
| 信仰 | 15（火焰赐予我力量） |
| 感应 | 11（基础） |

### 玩法
双手持巨剑，使用**狮子斩（Lion's Claw）**作为主要攻击（超霸体、高伤害、将人形敌人击倒在地）。清杂兵用轻攻击横扫。Boss战使用**火焰赐予我力量**（信仰15，身体Buff +20%物理伤害）和**黄金树立誓**（战灰版——在匕首上附魔切换使用）。喝下**力量瘤结晶露滴**+**蓝秘密露滴**灵药——无限时间的力量加成用狮子斩最多释放6次而零FP消耗。

此构筑并非花哨——它靠高韧性、有效HP超过2,000且每次狮子斩击中输出1,200－1,500伤害。纯物理意味着没有元素抗性问题。

## 2. 敏捷出血——尸山血海浪人

### 概述
充分利用自发布以来始终顶级的**尸山血海**。战技尸横遍野造成巨额出血积累和火焰伤害——三击触发大多数敌人出血（造成百分比最大HP伤害）。

### 装备
- **右手1**：尸山血海+10
- **右手2**：长牙+25（切腹战灰用于Buff）
- **左手1**：龙飨印记+10（用于火焰赐予我力量和血焰刀刃）
- **护甲**：白面具（提升20%出血伤害）、浪人铠甲、浪人臂甲、浪人腿甲
- **护符**：腐败翼剑徽章、鲜血君王的欢愉、亚历山大碎片、卡利亚徽章

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 55 |
| 集中力 | 20 |
| 耐力 | 30 |
| 力量 | 12（基础需求） |
| 敏捷 | 55 |
| 智力 | 9（基础） |
| 信仰 | 15（火焰赐予我力量） |
| 感应 | 50 |

### 玩法
战斗前：双持左手印记释放**血焰刀刃**于长牙和**火焰赐予我力量**。Buff后，切换至尸山血海并开始连发战技**尸横遍野**。因感应50而造成的出血积累几乎即时触发获得鲜血君王的欢愉的+20%伤害增益。当Boss出血免疫率提升时，切换至**切腹**长牙穿刺自己，获得攻击力增益并在不依赖敌方出血触发的情况下维持压力。

这个构筑在50秒内可清除大部分非出血免疫的回忆Boss。玛莲妮亚几乎在其水鸟乱舞动画完成前就会死亡。

## 3. 智力法师——卡利亚宫廷法师

### 概述
纯粹施法者，究极玻璃加农炮。近距离极度脆弱，但具备一击清屏并远距离清除Boss的能力。对于新游戏+和经验丰富的玩家而言最佳。

### 装备
- **右手1**：卡利亚权杖+10（或卢瑟特的辉石杖+10）
- **右手2**：暗月大剑+10（寒冷质变）
- **左手1**：水母盾（战技持续20%伤害Buff，双手保持）
- **护甲**：魔女帽子（雪花）、雷亚卢卡利亚长袍、女王腕套、女王腿甲
- **护符**：魔力对蝎、拉达冈的肖像、葛孚雷的肖像、献斗剑护符

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 45 |
| 集中力 | 40 |
| 耐力 | 15 |
| 力量 | 16（暗月大剑需求） |
| 敏捷 | 20（施法速度） |
| 智力 | 80 |
| 信仰 | 7（基础） |
| 感应 | 9（基础） |

### 玩法
核心循环：启用水母盾战技→用**辉石魔砾**远程牵制→魔法之境+灵药圣杯瓶Buff叠满→**亚杜拉的月光剑**横扫一切或**彗星亚兹勒**融化Boss。

灵药组合：**魔力破露滴**+**智力瘤结晶露滴**。在可蓄力法术的魔法之境中，彗星亚兹勒每跳可输出4,000+伤害。蓝秘密露滴给予15秒无限FP——15秒不间断彗星亚兹勒可输出超过60,000伤害。极少有Boss能活过这15秒。

## 4. 信仰——亵渎圣剑圣骑士

### 概述
游戏中最舒适的构筑。亵渎圣剑的战技**掠夺烈焰**造成火焰伤害并偷取生命——每次命中回复10%最大HP + 150。可以远距离用华丽的大范围AOE扫荡，同时维持近乎无限的生命值。

### 装备
- **右手1**：亵渎圣剑+10
- **右手2**：神躯化剑+10（用战技范围清杂兵）
- **左手1**：黄铜盾+25（卡利亚奉还）
- **护甲**：拉塔恩套装（完美的负重防御平衡）
- **护符**：亚历山大碎片、火对蝎、龙徽大盾护符、卡利亚徽章

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 55 |
| 集中力 | 25 |
| 耐力 | 35 |
| 力量 | 22（双手持基础需求） |
| 敏捷 | 15 |
| 智力 | 9（基础） |
| 信仰 | 60 |
| 感应 | 20（提高异常状态效力？不，对不起） |

### 玩法
非常简单：锁定敌人→按L2→释放掠夺烈焰。重复。你会在100米外击杀敌人，同时每次AoE击中后获得回复。开战前发动**黄金树立誓**对队伍造成巨额+15%伤害和+10%减伤。灵药中添加**火焰破露滴**。大多数回忆Boss、所有开放世界遭遇和所有地牢就只是不断按L2直到结束。

对于火焰免疫的敌人（火焰巨人等），切换至神圣伤害的**神躯化剑**或使用**古龙雷击**（高信仰下伤害极高）。这是从开始到NG+7最便捷的构筑。

## 5. 双刀流血——跳劈斩击构筑

### 概述
双持同类型两把武器用L1跳劈击中4次。对每个敌人施加疯狂高频率的出血。这是DPS最高的构筑之一，但要求近战搏杀。

### 装备
- **右手1**：长牙+25（血腥质变，切腹战灰）
- **右手2**：打刀+25（血腥质变，切腹战灰）
- **左手1**：胁差+25（格挡工具，随时可卸除）
- **护甲**：白面具、猛禽黑羽（强化跳跃攻击）、其余任意（保持中负重）
- **护符**：鲜血君王的欢愉、腐败翼剑徽章、爪护符、米莉森的义手

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 55 |
| 集中力 | 15 |
| 耐力 | 25 |
| 力量 | 11（基础） |
| 敏捷 | 65 |
| 智力 | 9（基础） |
| 信仰 | 15（火焰赐予我力量） |
| 感应 | 55 |

### 玩法
主循环：使用双**切腹**穿透自身获得每次攻击+30物理和50出血积累，叠加成为绝对怪物。通过你的头盔和白面具及护符，每次跳劈施加300+出血积累——对大多数Boss来说一两次跳劈即触发出血。每次跳L1落地对大多数Boss造成1,800+伤害。

弱点：极度脆皮。但输出仅次于智力全叠加。对于出血免疫的敌人（拉达冈、艾尔登之兽等），一个备选选项是切换至**寒冷质变双曲剑**触发冻伤的替代方案。

## 6. 龙飨——龙飨圣职

### 概述
游戏中最高伤害潜力。利用龙飨印记配合高信仰/感应，龙飨祷告造成破格的伤害。龙母的强化提供额外加成。

### 装备
- **右手1/左手1**：双龙飨印记+10（双持伤害叠加）
- **右手2**：蚁刺剑+25（血质变，剧毒雾战灰——施加腐败+剧毒+出血）
- **护甲**：银泪面具（+8感应）、浪人套其余（轻装）
- **护符**：群聚信徒的立誓布、龙徽大盾护符、拉达冈的肖像、葛孚雷的肖像

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 55 |
| 集中力 | 35 |
| 耐力 | 20 |
| 力量 | 10（基础） |
| 敏捷 | 20 |
| 智力 | 9（基础） |
| 信仰 | 45 |
| 感应 | 55 |

### 玩法
核心法术循环：**龙雷**→**腐败吐息**→**龙焰**。开战时用**黄金树立誓**和**火焰赐予我力量**。灵药：**信仰瘤结晶露滴**+**蓝秘密露滴**。解锁的龙吐息造成破格的AoE伤害，且由于高信仰/感应及双印记加成造成巨额伤害。

腐败吐息对付笨重且安全的Boss（火巨人等），让他们从100%血量腐烂至0。龙雷在大多雷弱敌人身上打出4,000+伤害。这是同时兼具持续伤害和高爆发伤害的最佳构筑。

## 7. 拳套力量——岩石之拳角斗士

### 概述
少数拳套需求但回报丰厚的构筑。近身战专用——你与Boss亲密接触并靠超强韧性和Lifesteal Fist存活。极其有趣，但技能曲线陡峭。

### 装备
- **右手1**：铁球拳套+25（厚重质变，忍耐或狮子斩战灰）
- **右手2**：巨星锤+25（祈祷一击用于治疗，可选）
- **左手1**：无（双持拳套双手拿一样可接受）
- **护甲**：斗士套装
- **护符**：蓝色舞娘、腐败翼剑徽章、米莉森的义手、龙徽大盾护符

### 属性（150级）
| 属性 | 点数 |
|----------|-------|
| 生命力 | 60 |
| 耐力 | 45 |
| 力量 | 80 |

### 玩法
核心计划：贴身并将Boss打进断连眩晕状态。用忍耐破招进行交易。拳套攻击速度快得离谱且造成出奇高的韧性伤害。许多Boss会被愤怒的拳击无休止的打断连招。

对于无法靠近的Boss（龙类），切换至使用**兰斯**（长矛）的骑马战术。这是纯粹的物理极致乐趣——没有花哨的法术、没有状态异常、只有拳头和意志。

## 8. 黑夜女巫与火焰修士（DLC）

### 概览
DLC引入了大量新武器和法术。目前最佳选择：
- **反手剑**：极快、高出血、通过快速两刀连击打击。
- **古龙之爪**：闪电缠绕的拳套，造成巨大的雷电伤害并使敌人进入眩晕锁定。
- **雷菈娜的双剑**：双持直剑，用双光与焰的剑舞进行高输出。

等待更多DLC测试。

## 职业起始推荐

对于追求极致优化者：
- **力量构筑** → 流浪骑士（最佳起始装备）
- **出血/敏捷构筑** → 武士（始有长牙，一把顶级武器）
- **魔法构筑** → 观星者（始有辉石杖+魔法）
- **信仰构筑** → 忏悔者（始有加血祷告）

记住：起始职业仅是将属性分布于你最想要的方向。对于一个150级构筑，100级后的属性投入将令任何起始差距近乎无形。
