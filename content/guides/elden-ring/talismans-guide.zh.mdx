## 护符系统

护符是《艾尔登法环》的装备系统，提供被动增益。你同时最多可装备**4个护符**（通过击败恶兆妖鬼和黄金葛德温可获得更多扩展护符插槽，最终抵达**4个插槽**）。在游戏本体 + DLC中共有**117种护符**。

本指南关注最重要的护符——那些能改变构筑表现、在Boss战中救你一命或实质性提升游戏舒适度的护符。

---

## S级：核心构筑基石

### 1. 亚历山大的碎片 / 战士壶碎片

**战技伤害+15%（普通版仅+10%）**
- **位置：** 亚历山大支线的最终奖励（在法姆亚兹拉完成决斗）。或杀掉亚历山大以获取较弱的+10%版本。
- **为何为S级：** 几乎所有构筑都使用战技。亵渎圣剑的战技因此护符提升15%后拥有更高的生命窃取。月隐的战技因此提升可观伤害。

### 2. 龙徽大盾护符

**大幅提升物理伤害减免。**
- **位置：** 逐渐崩毁的法姆亚兹拉，在**龙教堂屋顶**附近，找到石剑钥匙雾门后的宝箱。
- **为何为S级：** PvE内容中最大的防守增益。在50生命力下，该护符可将承受伤害降低约20%。终局游戏中几乎必需的生存工具。

### 3. 拉达冈的肖像

**缩短施法时间（相当于约+30虚拟敏捷）。**
- **位置：** 雷亚卢卡利亚学院，讨论室赐福旁，爬梯后箱子。或通过兑换**学院辉石钥匙**后在教室中获取。
- **为何为S级：** 对任何施法构筑而言，这是必需装备。更快的施法=在任何Boss连招窗口内触发更多法术。

## A级：构筑专属必备

### 4. 鲜血君王的欢愉

**当附近发生出血时，攻击力+20%持续20秒。**
- **位置：** 王城下水道，弃置恶兆的地底，击败**恶兆之子蒙格**后的宝箱。
- **最佳构筑：** 任何使用**尸山血海**或双武器的构筑。该护符在你触发第一次出血后自动激活，让你放大的伤害持续整个Boss战。

### 5. 腐败翼剑徽章 / 米莉森的义手

**连续攻击后提升攻击力。** 腐败翼剑徽章提供更高比例加成，米莉森的义手额外提供+5敏捷。
- **位置：** 米莉森任务线（腐败翼剑徽章在后阶段的奖励）。宁姆格福的格威任务线进程限制。
- **最佳构筑：** 双武器构筑、跳劈构筑、爪、拳套。每个构筑的效率更高，配合连续快速的轻攻击。

### 6. 魔力对蝎 / 火对蝎 / 雷对蝎 / 圣对蝎

**+12%元素伤害，-10%物理抗性。**
- **位置：** 对蝎位于不同地点（魔力对蝎——魔法学院附近；火对蝎——火山官邸附近；雷对蝎——法姆亚兹拉；圣对蝎——深根底层）。
- **最佳构筑：** 施法构筑携带相匹配的对蝎护符，在配合50以上生命力时值得承受此代价。

### 7. 大壶众武护符

**提升装备负重约19%。**
- **位置：** 大壶在盖利德北端的**大壶竞技场**。击败三名骑士红魂NPC后获得。
- **最佳构筑：** 任何重装构筑必须装备。使你能够穿着最厚实的护甲且保持中翻滚。

## B级：强力但非必要

### 8. 绿龟护符

**加速耐力恢复（每秒约+8耐力恢复速度）。**
- **位置：** 啜泣半岛，始源之湖附近的**召唤水村**地下宝箱。
- **为何为B级：** 任何时候都有用，但相比专用护符无独特加成。对于频繁耗尽体力的近战构筑是可靠的选择。

### 9. 黄金树的恩惠+2

**最大生命值+4%，耐力+10%，负重+8%。**
- **位置：** 灰城罗德尔王城（击败黑剑后），从王城的一处尸体上拾取。
- **为何为B级：** 三重全面增益极具价值，但游戏终局才可获得+2版本。+1和+0版分别见于王城下水道和盖利德神授塔——尽早拾取。

### 10. 克莱普的印记

**装备时提升获得卢恩+20%。**
- **位置：** 法洛斯要塞（盖利德）。
- **为何为B级：** 无战斗增益，但是提高刷怪效率的重要舒适装备。与**黄金粪金龟**（20%）叠加达到40%总加成。

### 11. 银色粪金龟

**物品发现率+75。**
- **位置：** 化圣雪原，通往圣树的密道隐藏路径。
- **为何为B级：** 对于刷取稀有掉落的构建/武器/护甲至关重要。对提升游戏效率具有极高价值。

---

## C级：利基用途

### 12. 献斗剑护符

**满HP时攻击力+10%。**
- **位置：** 火山官邸，艾格蕾教堂附近一处被暗杀者尸体掉落。
- **最佳构筑：** 远程施法（满HP时触发），因你可在安全距离外维持满血。

### 13. 远箭护符

**弓和弩的射程提升。**
- **位置：** 雷亚卢卡利亚学院，学院正门前。
- **最佳构筑：** 纯远程构筑，对于风筝极其有用。

## 护符组合建议

### 通用近战
```
龙徽大盾 + 大壶众武 + 亚历山大的碎片 + 绿龟/黄金树的恩惠
```

### 出血构筑
```
鲜血君王的欢愉 + 腐败翼剑徽章 + 亚历山大的碎片 + 龙徽大盾
```

### 施法构筑
```
拉达冈的肖像 + 魔力对蝎（或相匹配） + 献斗剑护符 + 龙徽大盾
```

### 刷怪构筑
```
金色粪金龟 + 银色粪金龟 + 绿龟 + 黄金树的恩惠
```
