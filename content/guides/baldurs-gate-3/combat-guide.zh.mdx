## 战斗基础快速复习

### 回合制 vs 实时
BG3战斗是严格回合制。你的敏捷决定先攻顺序——高敏捷的角色先行动。先攻相同则由d4随机决定。

### 行动点
**动作**：攻击/施法/冲刺/推击/使用物品/协助/脱离
**附赠动作**：跳跃/推击/部分法术（治疗真言、灵体武器）/双持副手攻击/愤怒/狡猾动作
**反应**：借机攻击/法术反制/护盾术/地狱斥责/羽落术

### 攻击投骰公式
`d20 + 属性修正 + 熟练加值 + 武器附魔 + 其他加值 >= 目标AC`

### 法术豁免难度等级（DC）
`8 + 属性修正 + 熟练加值 + 法术DC加成装备`

## 进阶战斗概念

### 1. 环境互动：战斗在你动作之外

BG3战场充满可互动元素：
- **吊灯**：射下绳索可使其坠落造成钝击伤害
- **油桶/火药桶**：火焰可引爆
- **水面**：雷电/冷冻法术产生额外效果（感电水面、冰面）。闪电箭能感电水面使所有接触者受到额外闪电伤害
- **毒云/云雾**：提供遮蔽（远程攻击劣势）或伤害
- **高地**：远程攻击和投掷从高处获得+2命中加值
- **深渊**：推击可即时击杀——将敌人推入无底深渊无需造成伤害

**大师提示**：强力职业如战技大师可以将推击作为附赠动作，再用动作+动作如潮继续输出。

---

### 2. 专注系统：战斗中最关键的机制

一次只能专注一个需要专注的法术。受到伤害时需通过体质豁免（DC10或受伤量一半，取较高值）维持专注。

#### 保持专注的技巧
- **战斗施法者专长**：专注检定优势
- **透明护甲/体质豁免装备**：叠加数值加成
- **远离前线**：不进入敌人近战范围自然接受更少伤害

#### 顶级专注法术
| 法术 | 环位 | 效果 |
|--------|------|--------|
| 加速术 | 3环 | 目标每轮获额外动作、+2AC、敏捷豁免优势 |
| 人类定身术 | 2环 | 麻痹目标：所有攻击自动重击。近战内攻击优势 |
| 怪物定身术 | 5环 | 同上，影响任意生物类型 |
| 纠缠术 | 1环 | 区域内难行地形且每轮束缚敌人 |
| 法术反制 | 3环 | 反应取消敌人法术，无需专注但值得一提 |
| 召唤元素生物 | 5环 | 召唤水/风/土/火元素与我方并肩作战 |

### 3. 表面与状态效应

游戏最独特的机制就是战场表面。这里有几种关键效应：

#### 表面类型及组合
| 表面 | 创建方式 | 与其它效应结合 |
|--------|-----------|------------------------|
| 火 | 火球术、炼金术士之火 | 点燃油、火药 |
| 水 | 造水术、下雨 | 感电（雷电法术→额外伤害）/ 结冰（冷冻法术→难行地形） |
| 冰 | 冷冻法术在水上 | 难行地形，敏捷豁免或倒地 |
| 酸 | 酸液法术 | 腐蚀护甲（-2AC） |
| 毒云 | 毒云术、臭云术 | 伤害+遮蔽 |
| 油脂 | 油腻术 | 可点燃 |

### 4. 潜行与突袭

**突袭轮（Surprise Round）**：在战斗中攻击未察觉的交战方获得免费整轮。敌人完全跳过他们的回合。

**触发条件**：从隐匿状态发起攻击（蹲伏按钮或以附赠动作隐匿的角色）。

**最佳突袭使用者**：
- 刺客贼（自动暴击突袭目标）
- 幽暗追猎者游侠（突袭轮额外攻击+1d8伤害）
- 任何使用隐形术/隐形药水的角色

---

### 5. 群体控制优先级

按重要性排列：

1. **麻痹**（人类定身术、怪物定身术）— 敌人失能且攻击自动暴击
2. **沉睡/催眠图纹** — 敌人完全跳过回合
3. **恐惧** — 敌人逃跑并无法行动
4. **目盲** — 攻击劣势且法术无法指定目标
5. **束缚/纠缠** — 无法移动，敏捷豁免劣势
6. **击倒** — 近战范围内攻击优势，但其自身回合可站起
7. **减速** — 移动减半，-2AC，敏捷豁免劣势

### 6. 伤害类型优先选择

| 伤害类型 | 评价 | 原因 |
|------------|-------|--------|
| 力场 | S级 | 极少数敌人抗性/免疫 |
| 光辉 | A级 | 第二章大量不死族弱光 |
| 闪电 | A级 | 感电水面双倍伤害 |
| 火焰 | B级 | 优秀但许多敌人火抗 |
| 黯蚀 | B级 | 优秀但许多敌人黯蚀免疫 |
| 冷冻 | B级 | 配合水面好，但后期多抗 |
| 强酸 | C级 | 稀有的抗性，但伤害面低 |
| 毒素 | D级 | 极多免疫，尤其第二章后 |

## 队伍构成原则

### 标准4人小队模板
1. **坦克/前排**（野蛮人、战士、圣武士）—— 承受伤害
2. **物理输出**（游侠、游荡者、武僧）—— 持续单体伤害
3. **法术输出**（术士、法师、邪术师）—— 范围爆发和控制
4. **辅助/治疗**（牧师、诗人、德鲁伊）—— 回复、Buff

### 灵活变体
- **双施法阵容**：术士+法师+光明牧师+前排
- **全物理**：双战士+游侠+战争牧师（第二章效果差，但可行）
- **四邪术师**：魔能爆推击一切掉入深渊——玩笑组合但极娱乐
