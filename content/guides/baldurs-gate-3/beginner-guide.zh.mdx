## 欢迎来到费伦大陆

《博德之门3》是有史以来最庞大的CRPG之一——基于D&D第五版规则，拥有超过170小时的电影级过场动画和成千上万个有意义的选择。如果你从未玩过D&D或Larian Studios的游戏，看到角色创建页面那密密麻麻的属性时可能会懵掉。别担心——本指南将带你掌握所有基础知识。

---

## 角色创建基础

### 属性系统

D&D使用六项**属性值**（3-20），决定你所有行动的成功率：

| 属性 | 英文 | 影响 |
|----------|-------|--------|
| 力量 | STR | 近战攻击/伤害、跳跃距离、负重、力量豁免 |
| 敏捷 | DEX | 远程/灵巧武器攻击、护甲等级、先攻、敏捷豁免 |
| 体质 | CON | 最大生命值、专注豁免 |
| 智力 | INT | 法师施法、调查/历史/奥秘技能 |
| 感知 | WIS | 牧师/德鲁伊/游侠施法、察觉检定（发现陷阱） |
| 魅力 | CHA | 术士/邪术师/圣武士施法、所有对话说服/欺骗/恐吓检定 |

**指导原则**：你主要职业的属性决定你的**主属性**。将你主属性升到16（角色创建上限），体质至少14，敏捷至少12-14。剩余点数视情况分配。

### 属性修正值速查

属性值越高越好，但计算公式是 `(属性值 - 10) / 2` 向下取整：

| 属性值 | 修正值 |
|----------|---------|
| 8-9 | -1 |
| 10-11 | +0 |
| 12-13 | +1 |
| 14-15 | +2 |
| 16-17 | +3 |
| 18-19 | +4 |
| 20 | +5 |

**17=+3与16=+3之间无差别**——这就是为什么许多构筑停在16，等待到4级通过专长升到18。

## 战斗核心

### 动作经济

每轮（6秒）你获得：
- **1个动作（Action）**：攻击、施法、冲刺、脱离等
- **1个附赠动作（Bonus Action）**：跳跃、推击、部分法术/职业能力
- **反应（Reaction）**：每轮一次（借机攻击、法术反制、护盾等）
- **移动（Movement）**：等于你的速度值（英尺），可在动作间拆分

### 优势与劣势

这是游戏中最强大的机制之一：

| 状态 | 效果 | 常见来源 |
|--------|--------|---------------|
| **优势** | 掷两次d20取较高值 | 攻击倒地/目盲敌人，隐形攻击，从高处攻击 |
| **劣势** | 掷两次d20取较低值 | 目盲、中毒、远程攻击近处敌人 |

**经验法则**：优先寻求优势。优势约等于等效+5命中。这比普通的+1护甲/武器更有价值。

### 护甲等级（AC）

AC决定敌人的攻击是否命中。d20骰 + 攻击加值 >= 目标AC = 命中。

| 构筑类型 | 典型AC（前期） | 最高AC（后期） |
|-------------|------------------------|----------------------|
| 重甲坦克 | 18-19 | 22-26 |
| 中甲战士 | 16-17 | 19-21 |
| 轻甲/法师 | 13-15 | 16-19 |

### 伤害类型与抗性

- **穿刺/挥砍/钝击**：物理伤害，最通用的类型
- **火焰/冷冻/闪电/强酸/雷鸣**：元素伤害
- **光辉/黯蚀**：神圣/亡灵魔法伤害
- **心灵/力场**：精神/纯粹魔法力量（极少有抗性）

怪物拥有抗性（半伤）或免疫特定类型。右键「查看」敌人以获得这些信息——信息就是力量。

## 休息系统

### 短休（Short Rest）
- 每天2次
- 回复约50%生命（视职业而定）
- 邪术师回复法术位
- 战士回复动作如潮
- 部分能力在短休后重置

### 长休（Long Rest）
- 需要使用40份营地补给
- 完全回复全部生命值和资源
- 推进同伴剧情和过场事件
- **注意**：某些时间敏感的任务在长休后可能推进。在关键任务中频繁长休前先确保完成时间限制步骤。

### 何时休息

通用准则：1-2次战斗后短休。用完短休后长休。例外：纯法术构筑可在每次主要战斗后长休——40份营地补给很充裕。

## 技能检定

所有非战斗行动——对话、撬锁、察觉陷阱、游说等——都会进行**技能检定（Skill Checks）**。

| 常见技能 | 属性 | 使用场景 |
|--------------|----------|----------|
| 游说/欺瞒/恐吓 | 魅力 | 对话选项 |
| 察觉 | 感知 | 发现陷阱/隐藏物 |
| 巧手 | 敏捷 | 撬锁、偷窃 |
| 隐匿 | 敏捷 | 潜行不被发现 |
| 奥秘/历史/宗教 | 智力 | 魔法/历史/神学类知识 |

**建议**：队伍中始终有至少一个高察觉的人和一个高巧手的人（阿斯代伦是完美的巧手专家）。

## 第一部分：前期策略

### 螺壳舰（教程）

- 解救**影心**（位于第二个舱室）。
- 在操纵台前拾取**永燃之刃**（指挥官的火焰巨剑，需影心命令术或高输出的配合）。

### 海滩着陆后

优先级顺序：
1. 救起**影心**（昏迷在海滩）。
2. 找到**阿斯代伦**（坠毁船体西侧附近）。
3. 找到**盖尔**（不稳定传送门，路旁）。
4. 找到**莱埃泽尔**（被提夫林捕获，鸟笼中）。
5. 到达**翠绿林地**并进入德鲁伊树林，与**威尔**、**卡菈克**和商人对话。

## 推荐新手构筑

如果你对D&D机制不熟悉，以下是三个简单有效的构筑：

### 1. 战斗大师战士（纯战士12级）
- 简单粗暴但极其强大
- 主属性：力量 → 体质
- 战斗风格：巨武器战斗
- 专长：巨武器大师、警觉、力量提升
- 玩法：冲入敌阵、动作如潮、用卓越骰精准命中和控制敌人

### 2. 龙族血脉术士（纯术士12级）
- 高魅力对话 + 爆发伤害
- 主属性：魅力 → 体质
- 超魔法：瞬发法术、升阶法术
- 玩法：瞬发法术双火球术清场。升阶**人类定身术**控制强敌。

### 3. 光明领域牧师（影心默认可洗点至此）
- 完美团队辅助
- 主属性：感知 → 体质
- 关键法术：引导神力、灵体武器、群体治愈真言
- 玩法：保持全队站场，用光明牧师的引导神力清扫不死族

## 永远记住这三条规则

1. **先手必胜**：警觉专长（先攻+5）是游戏中最强的专长。你的团队先行动，你控制战斗。
2. **专注就是一切**：不要浪费你的专注位。保持像**加速术**或**人类定身术**这样的关键法术持续生效。未专注时你的队伍输出呈指数级下降。
3. **高地=胜利**：远程攻击从高处获得+2命中。推击可以一击致命（将敌人推入深渊）。利用地形。
