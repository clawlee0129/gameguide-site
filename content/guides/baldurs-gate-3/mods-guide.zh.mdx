## MOD入门

《博德之门3》拥有庞大且活跃的MOD社区。目前主要通过两个渠道获取模组：

1. **游戏内模组管理器（官方）**：2024年9月随补丁7推出。支持在主机和PC上直接浏览、安装和管理模组。由于受平台的限制，仅包含经过审批的MOD。

2. **Nexus Mods**：外部模组平台，提供最大范围的选择，包括改版游戏机制的MOD、自定义种族/职业、视觉增强、作弊工具等。需要**BG3 Mod Manager**工具进行安装。

---

## 安装步骤（Nexus Mods）

1. 下载并安装 **BG3 Mod Manager**
2. 从Nexus Mods下载MOD文件（通常为.pak格式）
3. 在BG3 Mod Manager中加载MOD并激活
4. 保存加载顺序并导出到游戏
5. 启动游戏，MOD应已启用

**注意**：MOD可能禁用成就。使用**Achievement Enabler**可绕过此限制。

## 必备MOD推荐

### 视觉与UI

| MOD名 | 功能 |
|---------|--------|
| **ImprovedUI** | 改善游戏界面，诸多MOD的前置要求 |
| **Native Camera Tweaks** | 解锁视角限制——更多电影式角度 |
| **Customizer's Compendium** | 解锁额外的角色创建选项（脸型、发型、纹身） |
| **Basket Full of Equipment** | 新增数百件护甲和衣物外观（纯外观，不影响数据） |
| **Tav's Hair Salon** | 新增150+发型 |

### 游戏性与机制

| MOD名 | 功能 |
|---------|--------|
| **5e Spells** | 新增数百个D&D第五版法术（来自扩展规则） |
| **Party Limit Begone** | 取消4人队伍限制——可带更多同伴一起冒险。注意：使战斗变简单 |
| **Tactician Plus** | 增强敌人AI和数值，平衡大型队伍或寻求挑战的玩家 |
| **Artificer Class** | 新增工匠职业（来自D&D扩展） |

### 物品与装备

| MOD名 | 功能 |
|---------|--------|
| **Faerûn's First Folio** | 新增数百种武器和护甲，融入游戏世界掉落 |
| **Enchanted Schematics** | 允许制作魔法物品 |
| **Legendary Equipment Upgraded** | 将大多数独特装备升级至+3，调整属性使其终局可用 |

### 优化与Bugs修复

| MOD名 | 功能 |
|---------|--------|
| **Community Fixes** | 修复大量未修补的bug |
| **Better Hotbar** | 改善快捷栏与物品管理 |
| **Auto Loot** | 自动拾取周围战利品 |

## 推荐新手MOD组合

最简单且不影响游戏性和成就的安全组合：
1. ImprovedUI + UI相关MOD前体
2. Customizer's Compendium（更多角色定制）
3. Native Camera Tweaks（更好的视角）
4. Better Hotbar（快捷栏改善）

想挑战更高难度或增加内容深度：
1. Party Limit Begone + Tactician Plus（平衡组合）
2. 5e Spells（新增大量法术多样性）
3. Artificer Class（新增玩法职业）

## MOD使用注意事项

- **多MOD兼容性**：部分MOD可能冲突。每次安装后查看BG3 Mod Manager中的警告。
- **游戏更新**：大补丁经常破坏MOD兼容性。更新后检查MOD作者是否发布了补丁。
- **存档安全**：安装MOD前备份存档。一些MOD（特别是新增自定义种族/职业的）可能使移除后存档无法加载。
- **主机玩家**：游戏内模组管理器是最佳选择，但选择种类有限。PC玩家可使用Nexus Mods获取更广泛支持。
