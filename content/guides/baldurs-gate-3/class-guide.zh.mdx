## 职业选择概述

《博德之门3》提供12个D&D第五版职业和46个子职业。本指南将每个职业按**上手难度**、**战斗角色**和**推荐构筑**进行分析。同时也会涵盖强力多职混搭。

---

## 入门级：最容易上手

### 战士（Fighter）

**角色定位：** 前线坦克/伤害输出
**推荐子职业：** 战斗大师（Battle Master）
**难度：** 极低

你想轻松砍穿一切？选择战士。战斗大师的卓越骰提供可恢复的控制能力（绊摔攻击、精准打击、恐吓攻击），其动作如潮在关键回合爆发双倍输出。所有护甲和武器擅长使其成为最简单的职业。

- **属性：** 力量17 / 敏捷14 / 体质16 / 智力8 / 感知10 / 魅力8
- **4级专长：** 巨武器大师
- **关键装备：** 永燃之刃（前期），银色湖中剑（中期），博德安的巨人杀手（终局）

### 野蛮人（Barbarian）

**角色定位：** 狂战士肉盾
**推荐子职业：** 狂战士（Berserker）
**难度：** 极低

愤怒模式减半所有物理伤害。你在狂暴下可以投掷敌人，用附赠动作投掷武器。狂战士获得狂怒投掷作为附赠动作，提供额外攻击。简单来说——你冲进20个敌人中，最后活下来的那个是你。

- **属性：** 力量17 / 敏捷14 / 体质16 / 智力8 / 感知10 / 魅力8
- **投掷构筑：** 专长酒馆斗殴者（+力量加倍至投掷攻击）
- **关键装备：** 回旋长矛（自动回手），尼鲁纳（第三章最强投掷武器）

## 中等级：需要一些理解

### 圣武士（Paladin）

**角色定位：** 爆发近战 + 团队光环
**推荐子职业：** 复仇之誓（Vengeance）
**难度：** 中等

圣武士的游戏计划：接近 → 至圣斩 → 重复。至圣斩消耗法术位以在攻击上增加2d8-5d8光耀伤害。复仇誓言获得仇敌誓言（对单一敌人攻击优势持续10回合）。6级解锁的防御光环让你附近的盟友获得你的魅力修正加值到全豁免。

- **属性：** 力量17 / 敏捷10 / 体质14 / 智力8 / 感知10 / 魅力16
- **爆发伤害：** 加速术+动作如潮+所有法术位转为至圣斩 = 一回合内消灭任何Boss
- **多职推荐：** 邪术师5/圣武士7（三打攻击+至圣斩用邪术师法术位）

### 游侠（Ranger）

**角色定位：** 远程伤害 + 开锁
**推荐子职业：** 猎人（Hunter）或幽暗追猎者（Gloom Stalker）
**难度：** 中低

幽暗追猎者在第一回合获得额外攻击+1d8伤害和+3先攻。猎人在11级时获得旋风攻击/齐射——对范围内的所有敌人进行攻击。同时擅长巧手（代替贼的开锁角色）。

- **属性：** 敏捷17 / 体质14 / 感知16 / 其余随意
- **专长：** 神射手
- **关键装备：** 泰坦弦弓（力量调整值加入伤害），多靶箭矢

## 法术职业：高回报，需理解

### 术士（Sorcerer）

**角色定位：** 爆发法术伤害
**推荐子职业：** 龙族血脉（Draconic）或风暴术士（Storm）
**难度：** 中等

超魔法是其核心身份——**瞬发法术**一回合释放两个法术，**升阶法术**给予敌人法术豁免劣势。风暴术士获得免费飞行脱离近战。龙族血脉在6级时获得+魅力修正的对应元素伤害。术士是游戏中的终极核弹——瞬发+升阶定身术后补刀解离术是完全合理的。

- **属性：** 魅力17 / 敏捷14 / 体质16 / 其余随意
- **多职推荐：** 风暴术士10/暴风牧师2（引导神力最大化雷电伤害），戏法轻松打出80+伤害

### 法师（Wizard）

**角色定位：** 万能施法者
**推荐子职业：** 防护（Abjuration）或占卜（Divination）
**难度：** 中等

法师通过抄写卷轴获得游戏中最大的法术库。占卜法师拥有预兆骰——可在关键时刻改变任何d20的掷骰结果。防护法师获得一个减伤护盾，让自己几乎不受伤害。

- **属性：** 智力17 / 敏捷14 / 体质16 / 其余随意
- **关键法术：** 火球术、法术反制、加速术、人类定身术、解离术、怪影杀手

## 高入门难度：曲线陡峭

### 德鲁伊（Druid）

**角色定位：** 控制 + 变身坦克
**推荐子职业：** 月亮结社（Moon）
**难度：** 较高

月亮德鲁伊获得更强的野生动物形态（枭熊、剑齿虎、元素执政官）。野兽形态的生命条独立于你的本体——这意味着你可以变两次大型生物，总共拥有三条命。大地德鲁伊更偏重施法控制。

- **属性：** 感知17 / 敏捷14 / 体质16 / 其余随意
- **玩法：** 变枭熊 → 使用碎地震击击倒敌人 → 变回人形 → 扔月光束或纠缠术 → 野兽形态结束再次变身
- **关键装备：** 变形者之戒（变形时+1d4全豁免）

### 诗人（Bard）

**角色定位：** 多面手——技能检定之神 + 控制法术
**推荐子职业：** 剑刃学院（Swords）
**难度：** 中等

诗人是交涉场合的无冕之王。剑刃诗人可使用剑舞作为武器攻击并获得额外AC或推击敌人。知识诗人获得额外魔法奥秘（可从任何职业偷取法术——包括圣武士的至圣斩和游侠的急速箭）。

- **属性：** 魅力17 / 敏捷16 / 体质14 / 其余随意
- **关键法术：** 凶兆之音（敌人豁免劣势）、怪物定身术

## 邪术师特殊章节

### 邪术师（Warlock）

**角色定位：** 魔能爆炮台 + 多职混搭核心

邪术师拥有游戏中最强的戏法**魔能爆（Eldritch Blast）**。配合痛苦魔爆祈唤（+魅力伤害至每一束魔能爆）和斥力魔爆（击退敌人），成为一个集伤害和控制于一身的无尽炮台。

- **属性：** 魅力17 / 敏捷14 / 体质16 / 其余随意
- **关键多职：** 邪术师2/邪术师3后几乎任何魅力职业都会混入（魔能爆加痛苦魔爆在5级后伤害飞跃）

---

## 最强多职混搭TOP 5

1. **邪术师2/术士10**：痛苦魔爆+瞬发魔能爆，每回合打出6束（12级后9束）
2. **游侠5/贼4/战士3**：单手弩构筑每回合打出4-5次攻击
3. **野蛮人5/贼3/战士4**：投掷构筑每回合4次掷矛
4. **圣武士6/术士6**：更多法术位=更多至圣斩
5. **武僧9/贼3**：徒手攻击流——每回合6次徒手击打
