## 法术位与环级

BG3的施法者使用Vancian法术位系统。每长休恢复所有法术位（术士用术法点可短休恢复），每环有不同数量的法术位。高环法术位可将低环法术"升环"施放以提高伤害/效果。

---

## 戏法：无限施放的基础

| 戏法 | 评价 | 理由 |
|--------|------|--------|
| **魔能爆** | S+ | 唯一的多束戏法。10级3束。全部可独立分配目标。配合痛苦魔爆+魅力修正伤害，斥力魔爆推人。 |
| **火焰箭** | A | 1d10火焰伤害。大量场景可引燃油/火药桶。 |
| **冷冻射线** | B | 1d8+减速。在特殊场景用于远程触发冷冻机制。 |
| **震撼之攫** | B | 1d8雷电，目标无法使用反应。对抗施法者专用。 |
| **酸液飞溅** | C | 溅射2目标，伤害低但可腐蚀。 |
| **毒液喷射** | D | 太多敌人免疫毒素。 |
| **光亮术** | 实用 | 解除暗影诅咒，照亮黑暗区域，非战斗必带。 |
| **交友术** | 实用 | 对话检定优势。注意：高难度下法术结束后NPC会敌意。 |
| **法师之手** | 实用 | 远距离触碰按钮/杠杆/物品。 |

## 1-3环：核心战斗法术

### 1环关键法术

| 法术 | 评价 | 说明 |
|--------|------|-------------|
| **护盾术** | S | 反应+5AC。近100%挡下一击。法师/术士游戏全程必备 |
| **治愈真言** | S | 附赠动作治疗。拉起倒地队友的终极工具 |
| **祝福术** | A | 3目标+1d4攻击和豁免。最稳定的团队Buff |
| **灾祸术** | A | 目标-1d4攻击和豁免。对高AC敌人先上 |
| **人类定身术** | S | 麻痹目标——近战范围内所有攻击自动暴击 |
| **油腻术** | B | 大面积倒地控制。后期不如催眠图纹 |
| **雷鸣波** | B | 推开一大群敌人——用来将人推下悬崖 |
| **法师护甲** | B | 无甲13+敏捷AC持续到长休。术/法必备 |

| 法术 | 评价 | 说明 |

| **黑暗术** | A | 大面积遮蔽——所有远程和法术目标失效。配合魔鬼视觉无敌 |

| **灵体武器** | A | 附赠动作召唤持续10回合。每回合自动攻击一次。不占专注！ |

## 4-6环：改变游戏格局

### 4环关键法术

| 法术 | 说明 |
|--------|-------------|
| **放逐术** | 将单一目标送出战场2回合。专注。精英敌人克星 |
| **冰风暴** | 大面积冷冻伤害+难行地形冰面 |
| **火焰护盾** | 10回合火焰/冰霜伤害反弹+相应抗性 |
| **高等隐形术** | 隐身不因攻击而中断。全程优势攻击 |

### 5环关键法术

| 法术 | 说明 |
|--------|-------------|
| **怪物定身术** | 人类定身术的升级版——影响任何生物类型 |
| **解离术** | 10d6+40力场伤害。将敌人生命降至0则化为灰烬 |
| **支配人类** | 控制单一人类为你战斗 |
| **召唤元素生物** | 召唤强力元素盟友。水元素有治疗光环 |
| **死云术** | 大面积持续黯蚀伤害 |

### 6环关键法术

| 法术 | 说明 |
|--------|-------------|
| **链状闪电** | 10d8跳跃最多4个目标。全游戏最佳AoE |
| **怪影杀手** | 12d8心灵伤害，目标若恐惧则优势攻击 |
| **解离术（升阶6环）** | 力场伤害提升至更高级 |
| **英雄盛宴** | 全队免疫毒素/恐惧/疾病，+12最大HP直到长休 |
| **阳炎射线** | 每回合重放的光束攻击。对不死族优势 |
