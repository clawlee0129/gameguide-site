## 引言

博德之门3横跨剑湾的三个宏大章节，从夺心魔飞船坠毁到博德之门街头。超过174小时的过场动画和数百个分支决策，一份完整的攻略对于见证所有主要故事节点而不错过关键内容至关重要。本指南涵盖三章的最佳故事路线，包括关键决策点、同伴里程碑以及如何达到最佳结局。

**剧透警告**：本指南包含全部三章的完整故事剧透。

## 序章：螺壳舰

你的旅程在一艘夺心魔螺壳舰上开始。你脑中有一个蝌蚪，有15分钟（游戏内时间，不是真实时间，但行动要快）在飞船坠毁前。

### 同伴招募
| 角色 | 位置 | 职业 |
|-----------|----------|-------|
| **莱埃泽尔** | 第一个房间，被困在舱中 | 战士 |
| **影心** | 第二个房间，敲门 | 牧师（诡术） |
| **我们** | 影心之后，头骨中的"大脑"生物 | 噬脑怪（临时） |

### 关键行动
1. 释放莱埃泽尔（与她的舱对话，然后使用右侧控制台——**DC 5力量检定**或让她自己释放）
2. 带上影心（她试图开门——同意帮忙）
3. 在舵轮室：避开两个与指挥官扎尔克战斗的坎比翁。**从扎尔克拾取永燃之刃**（影心用命令术：丢弃，55%成功率）。跑向信号转换器并连接它。飞船坠毁。

## 第一章：荒野与翡翠林地

### 海滩
你在海滩醒来。首要任务：招募同伴。

| 同伴 | 位置 | 招募 |
|-----------|----------|-------------|
| **影心** | 在海滩昏迷（起始点北面） | 叫醒她 |
| **阿斯代伦** | 坠毁地点西面，悬崖边 | 他求助关于"噬脑怪" |
| **盖尔** | 西北，悬崖上卡在故障的传送门中 | 拉他出来（力量检定，或通过安全的奥秘检定） |
| **莱埃泽尔** | 北方，被提夫林人困在笼中（靠近山隘） | 杀死提夫林人或说服他们离开 |
| **威尔** | 翡翠林地，训练提夫林儿童 | 在大门哥布林袭击后与他交谈 |
| **卡菈克** | 枯萎村落西北，河对岸（崛起之路） | 威尔的任务引导到她 |

### 翡翠林地故事节点

**大门战斗**：一队哥布林袭击者攻击林地大门。帮助提夫林人击退他们。**威尔**在此之后加入。

**德鲁伊政治**：林地内，德鲁伊正在执行**荆棘仪式**封闭林地——困住提夫林难民。关键NPC：
- **卡哈**：德鲁伊领袖（代理）。她暗中与暗影德鲁伊结盟。
- **赛夫洛**：提夫林领袖。希望林地保持开放。
- **阿拉贝拉**：偷窃西凡那斯神像被抓的提夫林儿童。救她（DC 12说服）。
- **内蒂**：德鲁伊治疗师。在你告诉她关于蝌蚪后，她试图毒杀你。通过检定或战斗。
- **拉斯**：反对卡哈的德鲁伊。他给你**狼之符文**用于隐藏宝库。

**隐藏宝库**：在议会图书馆（内蒂房间后面），在空底座上使用狼之符文打开秘密楼梯。里面：**悲伤**长柄刀（武器）和**塞恩死灵书**（按步骤：放入紫水晶，通过3次递增感知检定阅读——永久获得死者交谈）。

**卡哈的背叛**：搜索卡哈的箱子（藏在仆人区书架后面，瀑布之后）。找到一张便条引导你到**日照湿地**。在湿地中，在**腐烂沼泽**中找到木树精和魔蝠。在巨大的树干里，找到卡哈与暗影德鲁伊结盟的证据。返回并与她对质。通过说服/威吓检定使她收手。荆棘仪式停止。

### 哥布林营地与至上真神

主要故事推动你解决蝌蚪问题。多条线索指向哥布林营地：
- **哈尔辛**（失踪的大德鲁伊）据说在哥布林营地
- **至上真神**的邪教似乎与蝌蚪有关联
- 哥布林营地在枯萎村落西面

**路线**：翡翠林地→枯萎村落（哥布林挟持风车侏儒作为人质——救他，他与幽暗地域有关联）→哥布林营地。

### 哥布林营地攻略

从正门进入。使用夺心魔智慧权威通过哥布林检查点无需战斗（需要蝌蚪能力——超凡魅力）。

**神殿内部（破碎圣所）**：

| NPC | 位置 | 备注 |
|-----|----------|-------|
| **女祭司伽特** | 主厅 | 提供治愈你的蝌蚪。让她带你到她的房间。她试图让你入睡。如果你是精灵/半精灵（免疫睡眠），她会困惑并叫守卫。悄悄杀死她。拾取她的寄生虫标本。 |
| **德罗尔·拉格兹林** | 王座室，右侧 | 试图与死亡的夺心魔对话。让场景播放或打断。他是营地中最难打的战斗（5级，112 HP）。 |
| **明塔拉** | 后方房间，左侧 | 卓尔圣武士。她命令你攻击林地。你可以：同意（邪恶），拒绝（战斗），或忽略。 |

**释放哈尔辛**：在座狼圈（神殿右侧，经过一些向熊扔石头的哥布林儿童）。熊就是哈尔辛（德鲁伊荒野形态）。杀死哥布林。哈尔辛返回人形态并在神殿中加入为可控NPC。他坚持你在离开前杀掉3个领袖。

**清理神殿的策略**：
1. 先杀伽特（在她的房间中被隔离，容易潜行击杀）
2. 杀明塔拉（可选，但杀她是拯救林地的必要条件）。她房间附近的桥是可摧毁的。
3. 德罗尔·拉格兹林：从椽子上把他推进蜘蛛坑。或正常战斗——集中攻击他（他有指挥打击增益哥布林）。
4. 哈尔辛感谢你并返回林地。

### 庆祝派对

返回翡翠林地。提夫林人举办派对。这是浪漫触发点：

| 同伴 | 浪漫触发 |
|-----------|----------------|
| **影心** | 分享一瓶酒。选择调情选项。 |
| **阿斯代伦** | 他抱怨派对。问"你想要什么？" |
| **盖尔** | 给他展示一个魔法把戏（魔网场景）。想象接吻/牵手。 |
| **莱埃泽尔** | 她直接向你提出。她尊重支配力。 |
| **威尔** | 和他跳舞。 |
| **卡菈克** | 她热得不能碰（字面意思）。表达兴趣——第二章将解决这个。 |

### 山隘 vs. 幽暗地域决定

两条路线都通向第二章，但内容不同：

| 路线 | 关键内容 | 推荐给 |
|------|-------------|-----------------|
| **山隘（罗斯蒙修道院）** | 莱埃泽尔的养育间任务线、洛山达之血硬头锤、吉斯洋基传说 | 莱埃泽尔同伴、完美主义者 |
| **幽暗地域（熔炉）** | 精金熔炉、蕈人营地、尼尔任务线、灰矮人、深侏儒 | 任何人，特别是完成精金熔炉 |

**最佳路线**：两条都走！先完成幽暗地域（激活熔炉的传送点），然后返回走山隘。哈尔辛加入你的营地并警告你——但你可以两条都走。唯一的硬性截止是进入幽影诅咒之地。

| **熔炉** | 从塌方中救出尼尔（使用灰矮人的烟雾粉炸弹）。尼尔是一个至上真神教徒——与之战斗或加入他。拾取他的寄生虫。**使用精金熔炉**用秘银矿石制造2件物品（推荐盾牌+鳞甲或板条甲）。 |
| **眼魔遭遇战** | 塞伦涅哨站西面。一只眼魔在石化卓尔营地伏击你。 |

## 第二章：幽影诅咒之地

### 进入幽影诅咒

从幽暗地域（熔炉电梯）或山隘，你到达幽影诅咒之地。越深入，诅咒越强。

**光源**（强诅咒区域需要）：
- **月灯**（来自蛛化精灵卡尼斯或由巴尔萨泽制作——两种选项都在后面）
- **塞伦涅的祝福**（终焉之光旅店的伊索贝尔）
- **火把/光耀武器**（仅适用于轻微诅咒）

### 终焉之光旅店

第二章的枢纽。关键NPC：

| NPC | 角色 |
|-----|------|
| **贾希拉** | 竖琴手领袖，潜在同伴。她对你施展一个真言法术——通过检定或与整个旅店战斗。 |
| **伊索贝尔** | 塞伦涅的牧师，维持保护屏障。**不要让她死亡**——马库斯（炎拳叛徒）带着飞翼恐魔攻击。不惜一切代价保护伊索贝尔。如果她被绑架，屏障倒塌，终焉之光的每个人变成幽影诅咒亡灵（包括铁匠戴摩，你需要他为卡菈克任务）。 |
| **戴摩** | 提夫林铁匠。给卡菈克的引擎升级带来地狱铁（共2块）。第二次升级后，你可以触摸卡菈克。 |
| **拉斐尔** | 魔鬼。他出现在旅店外（陵墓入口附近）。他提出移除你的蝌蚪——以一定代价。签署契约或拒绝。 |
| **阿特·卡拉格** | 昏迷的炎拳。用破损的鲁特琴（从治疗之屋）唤醒他。他提到萨尼尔。开始"解除幽影诅咒"任务。 |
| **摩尔** | 提夫林小孩。拉斐尔对她的契约感兴趣。 |
| **罗兰** | 提夫林法师。他喝醉郁闷——他的兄弟姐妹被抓。说服他留下（DC 15说服）。 |

### 索姆家族

三个索姆亲属作为小Boss遭遇：

| 索姆 | 位置 | 策略 |
|-------|----------|----------|
| **盖林戈特·索姆**（收费站） | 收费站，西面道路 | 给她你所有的钱或战斗。摧毁漂浮骷髅（面孔）——每个给她加100 HP。 |
| **马鲁斯·索姆**（外科医生） | 治疗之屋 | 说服护士们"操作"他（DC 21说服，需要先阅读外科医生的笔记）。他躺在床上，护士们杀了他。 |
| **西索巴尔德·索姆**（酿酒师） | 残月酒馆 | 喝下他的挑战（3次体质豁免）。或给他讲故事（表演检定）。最后一次检定给你让他爆裂的选项。 |

### 莎尔铁手圣殿

地图北端的大神殿。这是第二章的主要地牢。

**圣殿中的拉斐尔**：他在入口附近出现，揭示阿斯代伦的伤疤是一份契约——亵渎飞升仪式的一部分。为拉斐尔杀掉恶魔尤吉（或打破他的契约）。这推进阿斯代伦的个人任务。

**三个暗影宝石试炼**：
1. **静步试炼**：潜行迷宫。不要被影子复制体抓住。顺时针沿着路径走。迷踪步使这个变得微不足道。
2. **自我试炼**：与你的队伍克隆人战斗。开始前卸下你的武器，然后在克隆人出现后重新装备——他们将没有武器。
3. **信仰飞跃试炼**：跳过一条隐形路径。看主厅的地板图案——路径是匹配的。或直接使用飞行/迷踪步。或让影心自动成功（她是莎尔信徒）。

**寂静图书馆**：与里面的黑暗审判官战斗。谜题：使用"沉默"按钮将图书馆长困在中心房间。开门，走进去，触发"沉默"使她被困。杀死她。暗夜之矛在一个封闭房间中（需要通过谜题祭坛）。

**恶魔尤吉**：拉斐尔的目标。尤吉在东侧密室。选项：
- 说服他杀死他的仆从、他的移位兽（妮莎），然后自杀（DC 21说服，然后21，然后21）。每次成功：一个压力源消失。
- 或与他战斗。他有110 HP，隐形能力和强大的连弩炸弹。使用识破隐形（瓦罗的眼睛）或妖火。

**幽影界（夜歌）**：

通过圣殿底部的池子进入幽影界。在这里你找到**夜歌**——一位名为**艾琳女士**的神人女性，塞伦涅之女，被囚禁了一个世纪。

**关键决定**：
- **影心杀死夜歌**→莎尔奖励她暗夜长矛。艾琳女士死亡。终焉之光屏障倒塌。伊索贝尔死亡。终焉之光的每个人变成亡灵。这会锁定你进入更黑暗的路线。
- **影心饶恕夜歌**→莎尔抛弃影心。影心的头发变白（塞伦涅的印记）。艾琳女士被释放并加入你对抗凯瑟里克的最终战斗。这是"善良"路线。

### 月出之塔攻城

幽影界之后，前往月出之塔。竖琴手+贾希拉加入攻城。

**一楼**：与至上真神教徒和监狱守卫战斗。释放囚犯（深侏儒+提夫林人）如果你还没有做——监狱在地下室。

**屋顶**：凯瑟里克·索姆。第一阶段：在屋顶与他战斗。50% HP时，他撤退到夺心魔殖民地。

### 夺心魔殖民地

第二章的最终地牢。你跳入月出之塔下的血肉坑。

**关键事件**：
- 找到**米佐拉**被困在舱中（如果威尔在队伍中）。释放她——她升级威尔的任务。
- 找到**赛夫洛**在舱中（如果你救了提夫林人）。
- **巴尔萨泽的实验室**：找到月灯制作站。再次遇见**我们**（来自螺壳舰）。
- **乔普的手术室**：另一个至上真神教徒在提取蝌蚪。令人恐惧。
- **威尔的决定**：米佐拉出现并给威尔一个选择：拯救他的父亲（拉文伽德公爵）以换取永恒的奴役，或打破契约并注定他父亲的命运。这决定威尔的结局。

**凯瑟里克·索姆/米尔寇战斗**：
- 第一阶段：平台上的凯瑟里克。他8级，AC 18，156 HP。
- 第二阶段：凯瑟里克血量降到0后，播放过场动画。夜歌（如果存活）提供巨大的优势。**米尔寇的使徒**升起（10级，AC 18，255 HP）。他可以吞噬亡灵祭司来治疗。
- **对抗米尔寇的策略**：杀死亡灵祭司阻止他的治疗。站在竞技场周围的平台上以避免他的拉扯范围攻击。他抵抗坏死和寒冷。使用至圣斩、火球术或任何光耀伤害。如果夜歌存活，她是不朽的，每次对他造成30+伤害。

**后果**：至上真神的神选者现身。你看到凯瑟里克的耐色石。主脑在城市之下。前往博德之门。

## 第三章：博德之门

### 利文顿与飞龙关

第三章的第一个区域是利文顿，城墙外的难民区。

| 位置 | 内容 |
|----------|---------|
| **末日马戏团** | 德利布斯小丑（被谋杀——散落的身体部位）、风巨灵阿卡比（作弊的轮盘——偷他戒指，赢得去楚尔特的旅行获取传奇三叉戟尼鲁纳）、与泽西诺进行爱情测试（推进浪漫） |
| **散手神殿** | 谋杀调查。洛根神父被杀。指向巴尔邪教。 |
| **夏瑞斯的爱抚** | 拉斐尔的闺房（楼上）。哈勒普，梦魔。**不要让哈勒普魅惑你**——他们偷走你的形态并使用它。沃斯在这里与你见面谈论释放俄耳甫斯。 |
| **飞龙石要塞** | 戈塔什的加冕礼。他成为大公爵。米佐拉出现并要求威尔的选择。拉文伽德公爵在这里被植入蝌蚪。钢铁卫士铸造厂被揭示。 |
| **钢铁王座** | 水下监狱。拉文伽德公爵+奥米卢姆+贡德俘虏。**定时6回合逃脱**。策略：分拆队伍，打开所有牢房，用迷踪步/任意门传送每个人。 |

### 下城区

一旦进入博德之门城区：

| 位置 | 任务/内容 |
|----------|---------------|
| **精灵之歌酒馆** | 君主的安全屋。租用楼上作为你的营地。 |
| **魔法杂物店** | 洛洛坎之塔。他想要夜歌。如果你带来她：与洛洛坎战斗。如果你站在洛洛坎一边：夜歌被重新囚禁（邪恶）。盖尔也可以在这里找到卡尔苏斯年鉴。 |

### 终局：对抗耐色脑

拥有全部三块耐色石（凯瑟里克、奥林、戈塔什），你面对耐色脑。

**君主 vs. 俄耳甫斯决定**：

这是游戏中最重要的选择：
- **站在君主一边**：信任夺心魔。他吞噬俄耳甫斯的力量。你+君主一起支配大脑。俄耳甫斯死亡。
- **释放俄耳甫斯**（需要俄耳甫斯之锤）：俄耳甫斯变成夺心魔（或你的一个队员）。君主离开并加入耐色脑。释放俄耳甫斯；他领导进攻。
- **变成夺心魔**：如果你自己是夺心魔，你可以单独支配大脑。卡菈克也可以自愿，这阻止了她因引擎而死亡。

### 最终战斗序列

1. **至高殿堂**：集结你的盟友（整个游戏中你帮助的每个派系都出现）。爬到顶端。
2. **卡尔苏斯之冠**：大脑顶端。螺壳舰轰炸。避免炮火标记（红色圆圈）。到达王冠。
3. **引导耐色石**：你的队员（有全部3块石头）打开通往大脑内部的传送门。
4. **耐色脑内部**：对抗龙+噬脑怪+大脑投影的最终战斗。杀死标记的保护王冠的敌人。然后用传送门引导石头。
5. **王冠密室**：耐色脑，现在脆弱。它有300 HP（平衡难度）。每回合它标记一个将被摧毁的平台。从标记平台上移开。杀死它。

### 结局

**如果你支配了大脑（变成至上真神）**：
- 邪恶结局：变成至上真神，奴役所有人。过场动画：你的同伴作为精神奴隶鞠躬（不祥的）。

**如果你摧毁了大脑**：
- 善良结局变体基于同伴任务结果：
  - 盖尔：将王冠归还密斯特拉（救赎）或变成神明（野心路线）。
  - 阿斯代伦：自由（衍体）或飞升吸血鬼（强大但更黑暗）。
  - 影心：塞伦涅信徒（父母获释或在来世）或黑暗审判官。
  - 威尔：阿弗纳斯之刃（自由）或公爵继承人。
  - 卡菈克：返回阿弗纳斯（与威尔/塔夫）或在码头上死去（令人心碎）。
  - 莱埃泽尔：骑红龙去对抗维拉基斯（如果俄耳甫斯存活/被释放）。
- **尾声派对**（6个月后在营地）：同伴重聚，分享信件，反思。
