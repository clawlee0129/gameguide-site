## 引言

博德之门3中的浪漫不仅仅是亲密场景——它是一个核心叙事系统，深化同伴故事线，解锁独特对话，并改变角色结局。每一位起源同伴加上哈尔辛、明塔拉和君主都可以被攻略，各自拥有不同的偏好、好感度触发和关系里程碑。本攻略涵盖每一位可攻略角色，包括好感度策略、关键对话选择，以及如何避免意外锁定浪漫路线。

## 浪漫机制概览

### 好感度系统
- **范围**：-50（敌对）到 +100（卓越）
- **阈值**：中等（20），高（40），非常高（60），卓越（80）
- 大多数浪漫在好感度达到**高（40+）**时触发，通常是在第一章派对或同等时刻
- 某些同伴除了好感度外还需要特定故事标记

### 伴侣独占性
- 大多数同伴在第二章前是**独占**的——与多个起源角色调情会让你锁定其中一人
- **哈尔辛**和**明塔拉**是例外（哈尔辛是多角恋，明塔拉不是）
- 某些同伴接受与特定其他人的多角恋：
  - **影心**+**哈尔辛**：接受
  - **阿斯代伦**+**哈尔辛**：接受（阿斯代伦出乎意料地对此淡然）
  - **卡菈克**+**哈尔辛**：接受（但只是暂时——她最终想要独占）
  - **影心**+**阿斯代伦**：可能一段时间，但其中一人会要求你做出选择

### 浪漫"标记"
"标记"是将你带入同伴浪漫路线的对话或场景。错过一个标记意味着你被锁定在外。第一章林地的派对是最常见的第一标记。

## 影心

**好感度策略**：尊重她的隐私（不要追问她的伤口），对动物和儿童表现出善意，反对至上真神，尊重塞伦涅（讽刺的是），避免不必要的残忍。

### 第一章
| 行动 | 好感度 |
|--------|----------|
| 从卡哈手中救出阿拉贝拉 | +5 |
| 抚摸小狗挠挠 | +5 |
| 给她莎尔神像（枭熊洞穴雕像） | +10 |
| 不追问她过去的经历 | +5 |
| 善待提夫林难民 | +5（多次） |
| 拯救提夫林人 | +5 |
| 不杀枭熊幼崽 | +5 |

**派对场景触发**：在哥布林/提夫林庆祝派对上，影心独自坐着喝酒。对话选项：
- "我来和你分享一瓶"→浪漫标记
- "也许以后吧"→仅是朋友

**第二个标记**：在幽暗地域，一次长休后，她透露她不会游泳但想学。夜兰花场景。

### 第二章
| 行动 | 好感度 |
|--------|----------|
| 给她一朵夜兰花（在幽影诅咒之地找到） | +10 |
| 不让她吃贵族菌蘑菇 | 她感谢无论哪种选择 |
| 在莎尔铁手圣殿信任她 | +10（不要干预她的祈祷） |

**莎尔铁手圣殿决定（关键）**：
- **鼓励她饶恕夜歌**→塞伦涅路线，头发变白，浪漫继续，她从莎尔那里获得自由
- **鼓励她杀死夜歌**→黑暗审判官路线，浪漫继续但她在情感上变得更加疏远。黑暗浪漫。

### 第三章
完成她的个人任务（悲伤之屋）。释放她的父母或让他们离开——两种选择都保持浪漫完好。

**浪漫场景**：海滩场景（长休，在马戏团爱情测试场景后）。最终浪漫场景是在月光下的海滩上，她敞开心扉倾诉她的感情，温柔而不露骨。

### 提示
- 影心是最慢热的浪漫。不要期待即时亲密——她的弧线是关于信任的。
- 你可以以任何性别或种族攻略她。
- 如果你想多角恋安排，她与哈尔辛兼容。

## 阿斯代伦

**好感度策略**：讽刺，支持他的独立，让他吸你的血，不要评判他的吸血鬼身份。

| 行动 | 好感度 |
|--------|----------|
| 让他咬你（第一个营地夜晚他偷袭时） | +10 |
| 当其他人发现他是吸血鬼时为他辩护 | +5 |
| 给他塞恩死灵书 | +5 |
| 为他杀死怪物猎人（甘德雷尔） | +10 |
| 支持他对力量的渴望 | +5（多次） |
| 在对话中刻薄/讽刺 | +1-3（频繁） |
| 接受他的伤疤是一首"诗" | +3 |

### 第一章派对
在派对上，阿斯代伦在一旁。选择对话："你想要什么？"而不是"希望你玩得开心"。他嘲讽地向你提出邀请。

**森林场景**：派对后长休。他建议在树林里过一晚。接受→浪漫标记设置。

### 第二章
**阿拉杰·奥布洛德拉（月出之塔）**：卓尔血液商人想让阿斯代伦咬她。**关键：支持他选择不做**。如果你强迫他，他感谢你但失去信任。如果你支持他的拒绝，他对你获得巨大尊重（+10，以及一个美丽的营地后对话）。

**拉斐尔/尤吉**：帮助他了解他的伤疤。杀死尤吉或完成拉斐尔的契约。

**告白场景**：在尤吉/阿拉杰事件后，阿斯代伦坦白他一开始是在操纵你但真正产生了感情。这是情感的转折点。

### 第三章
**卡扎多尔宫殿**：仪式。支持阿斯代伦选择停止仪式（不要飞升）。飞升使他成为飞升吸血鬼——强大但根本性地改变。他的"好"结局是选择不完成仪式。

### 提示
- 阿斯代伦可以攻略任意性别/种族。
- 他对多角恋感到自在（哈尔辛）。
- 对于扮演"抗拒黑暗冲动"角色的玩家，这个浪漫特别有意义——打破黑暗主人的束缚这一共同主题。

## 盖尔

**好感度策略**：对知识充满好奇，欣赏魔法，善待儿童/动物，避免不必要的暴力。

| 行动 | 好感度 |
|--------|----------|
| 给他魔法物品（第一章共3件） | 每次+5 |
| 对他的魔法天赋表现出兴趣 | +5 |
| 不要嘲笑他的状况 | +5 |
| 善待提夫林儿童 | +5 |
| 拯救林地 | +5 |

### 第一章
**魔网场景**：长休。盖尔提议给你展示一个魔法把戏。跟随魔网场景选项。关键时刻：当魔网连接时，想象浪漫的事情（吻他，牵手）否则魔网消散。选择"想象他的头被钉在尖刺上"（想象斩首）会将你锁定在外。

**派对场景**：盖尔在注视魔网。调情。他笨拙但接纳。

### 第二章
**伊尔明斯特场景**：密斯特拉的选民到达。盖尔被告知牺牲自己。在情感上支持他。

**观星场景**：长休。盖尔创造一片魔法天空。主要的浪漫场景。他对于自己与密斯特拉的关系很脆弱。

### 第三章
**卡尔苏斯年鉴（魔法杂物店）**：盖尔得知王冠是真实的。他考虑使用它成为神明。

**小船场景**：盖尔个人任务的高潮。说服他寻求密斯特拉的宽恕并归还王冠，或者鼓励他的野心成为神明。小船场景是最终浪漫场景——写得非常优美，盖尔施展星界投影。

### 提示
- 盖尔是最一夫一妻制的同伴。他想要独占。
- 作为术士或其他奥术施法职业攻略他会有独特对话。
- 他的结局根据你是否鼓励密斯特拉之路或他的野心而变化巨大。

## 莱埃泽尔

**好感度策略**：直接，展现力量，尊重吉斯洋基文化，展现支配力。

| 行动 | 好感度 |
|--------|----------|
| 在战斗中展现力量 | +1-3（频繁） |
| 在对话中直接果断 | +3 |
| 在吉斯洋基事务上支持她 | +5 |
| 展现支配力（她尊重这个） | +5 |
| 让她审问佐鲁 | +5 |

### 第一章
**第一次提议**：非常早（大约第3-4次长休）。她说她想要"品尝"你。接受=浪漫标记。她尊重力量和直接。

### 第二章
**伊蕾柯养育间**：在吉斯洋基对抗中站在她一边。不要让扎伊希斯克杀了她（通过检定或将她拉出来）。

**挑战场景**：长休。她挑战你决斗（她想要被支配）。赢得战斗但在最后选择屈服于她——同时显示力量和脆弱。这是情感的转折点。

### 第三章
**维拉基斯的背叛**：支持莱埃泽尔拒绝维拉基斯。释放俄耳甫斯。

**日出场景**：最终浪漫场景。莱埃泽尔观看日出——这是她在星界从未体验过的。感人至深。

### 提示
- 莱埃泽尔是最有侵略性的浪漫。她主动来接近你。
- 她的浪漫弧线是关于学习脆弱和自由。
- 如果你释放了俄耳甫斯，她可能选择和他一起骑红龙去对抗维拉基斯。你可以加入她，或者她离开而浪漫结束——一个苦乐参半的结局。

## 卡菈克

**好感度策略**：善良，保护无辜者，憎恨奴隶贩子和魔鬼，热情。

| 行动 | 好感度 |
|--------|----------|
| 帮她找到地狱铁 | 每次+10（需要2块） |
| 杀死"提尔的圣武士"（扎瑞尔的特工） | +10 |
| 善待提夫林人 | +5 |
| 热情/兴奋 | +3 |
| 不要投靠哥布林 | +5 |

### 第一章
招募她，给她带地狱铁交给戴摩（德鲁伊林地）。第一次升级：她可以触摸而不会灼伤。

**营地场景**：第一次升级后长休。她在冷却。你可以"尝试触摸她"→接吻场景。浪漫标记设置。她确实冷却下来，你们分享一个吻。

### 第二章
**第二块地狱铁**（在终焉之光旅店交给戴摩）。这是关键的——如果戴摩死亡（伊索贝尔被绑架），卡菈克永远无法升级，浪漫不能在身体上推进。

**浪漫场景**：第二次升级后长休。她可以安全被触摸。亲密场景——她欣喜若狂。

### 第三章
**约会场景**：长休。她在博德之门带你去约会——简单、甜蜜，因为她的引擎状况而令人心碎。

**决定**：她的地狱引擎在衰竭。结局选项：
- 和她一起返回阿弗纳斯（你和/或威尔）。她不会死亡但生活在炼狱中。
- 她在码头上平静地死去（情感上但接受）。
- 变成夺心魔——引擎稳定，她存活。

### 提示
- 卡菈克是最情感开放的浪漫。她把心放在袖子上（字面意思——心脏在燃烧）。
- 她处境的悲剧性使这成为最具情感冲击力的浪漫之一。
- 她最初愿意与哈尔辛共享但最终想要独占。

## 威尔

**好感度策略**：英雄主义，保护无辜者，反对魔鬼和怪物。

### 关键时刻
- 帮助提夫林人→+10
- 拯救林地→+10
- 不杀无辜者→+5
- 在对话中英雄行为→+1-3频繁

**跳舞场景**：长休，第二章。威尔邀请你跳舞。接受→浪漫标记。

**米佐拉的契约**：在契约决定中支持威尔。浪漫在第三章以求婚（戒指场景）达到高潮。

---

## 哈尔辛

**好感度策略**：善待自然，帮助林地，拯救萨尼尔。

哈尔辛的浪漫要到第三章才开始。他直接向你提出。他是多角恋，不会干涉起源角色的浪漫。他的浪漫场景涉及他的熊形态（有意为之，处理得体）。

---

## 明塔拉

唯一的"邪恶"浪漫选项。为她屠杀林地。她的浪漫在第一章纯粹是身体接触，在第二至三章发展情感深度。她是独占的（不多角恋）。

---

## 君主

在第三章，你可以选择与君主（夺心魔形态）有一次浪漫接触。这……令人难忘。且有争议。它不会锁定其他浪漫路线。

---

## 浪漫锁定预防

| 错误 | 后果 | 解决方案 |
|---------|-------------|----------|
| 错过第一章派对标记 | 浪漫永不开端 | 在派对前重新读档 |
| 未升级卡菈克引擎 | 浪漫停滞 | 必须获得两次升级 |
| 杀死夜歌（对塞伦涅影心不利） | 浪漫转向黑暗审判官 | 浪漫继续但她的性格改变 |
| 强迫阿斯代伦咬阿拉杰 | 他失去信任，浪漫受损 | 重新读档，支持他的拒绝 |
| 鼓励盖尔野心而不涉及密斯特拉 | 他的结局是神明之路 | 在第三章小船场景谨慎选择 |
| 让伊索贝尔死去 | 戴摩死亡，卡菈克无法升级 | 必须保护伊索贝尔 |

---

博德之门3中没有"最佳"浪漫——每位同伴的弧线探索了创伤、自由、救赎和爱的不同主题。影心从邪教徒到自由女性的旅程，阿斯代伦重获自主权，卡菈克尽管命运如此却决心充实生活。选择最能引起你共鸣的故事。
