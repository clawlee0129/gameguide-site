# 赛博朋克2077：恋爱、同伴与关系结局

## 概述

《赛博朋克2077》有四个可恋爱角色，每个都有特定的性别/声音/体型要求、多任务关系弧线以及独特的结局条件。恋爱不仅仅是支线内容——你的恋爱对象的任务线直接决定哪些基础游戏结局可用，而你的关系状态影响对话、尾声场景甚至游戏玩法加成（公寓互动、礼物和消息）。

本指南详细涵盖每一条恋爱路线：要求、关键对话选择、约会机制、冲突解决，以及每条恋爱关系如何与五种结局互动。剧透部分已做标注。

## 帕南·帕尔默（游牧民）

### 要求

| 条件 | 详情 |
|------|------|
| 体型 | 男性（男性声音和体型） |
| 声音 | 仅限男性V |
| 出身 | 任意 |
| 任务线 | 必须完成幽灵小镇、雷霆破裂、战时的生活以及公路女王 |
| 关键属性检定 | 无——帕南的恋爱完全由对话驱动 |

### 任务链

**幽灵小镇**：在日落汽车旅馆见到帕南。在找回她的车之后的对话中，选择："我只是在照看你"和"你担心起来还挺可爱的"。避免轻蔑或纯粹交易的回应。在纳什之后的汽车旅馆，选择"你不是一个人，帕南。"

**雷霆破裂**：在变电站与康陶侦察兵交战后，帕南在篝火旁请你喝一杯。选择："敬帕南"在敬酒时以及"也许你应该留下"当她说要离开阿德卡多时。

**战时的生活**：这是关键任务。AV坠毁后，当帕南在营地与索尔争吵时，站在帕南一边。告诉索尔："帕南救了你的命"和"她在康陶这件事上是对的"。之后在悬崖上与帕南的安静时刻，选择："你可以依靠我。"

**公路女王**：触发恋爱的任务。帮助帕南从军用科技车队中偷取蛇怪坦克。在蛇怪内部的校准序列中，帕南伸手去握V的手。选择："我也想触碰你"以触发恋爱场景。其他任何选择都永久锁定。

### 关系动态

一旦建立恋爱关系，帕南会定期给V发消息，包括任务更新、对索尔的抱怨和调情消息。你可以邀请她到V的任意公寓——她会到访，评价装饰，你们可以睡在一起（施加临时+20%生命值经验加成）。她偶尔留下礼物：藏匿点中的阿德卡多夹克和她的步枪"守望"（如果此前在"风暴骑士"中没有拿）。

### 结局条件

帕南的恋爱是**星星**结局的必要条件。如果你与帕南处于恋爱关系并选择阿德卡多路线，她陪伴V离开夜之城，尾声展示你们两人开始新的生活。如果你选择"太阳"结局，帕南在语音信箱蒙太奇中与你分手——如果V选择佣兵生活而非氏族，她不会等待V。

在**高塔**结局（"往日之影"新结局）中，帕南拒绝与V通话。她的语音留言透露她已经向前迈进，不想重新揭开旧伤疤。

## 朱迪·阿尔瓦雷斯（技术高手）

### 要求

| 条件 | 详情 |
|------|------|
| 体型 | 女性（女性声音和体型） |
| 声音 | 仅限女性V |
| 出身 | 任意 |
| 任务线 | 必须完成自动爱情、中间空间、灾难现场、双重生活、两面、前任因素、谈论革命、双鱼座和金字塔之歌 |
| 关键属性检定 | 无——朱迪的恋爱完全由对话驱动 |

### 任务链

**自动爱情到双重生活**：这四个任务是建立朱迪信任的必要条件。在"灾难现场"中，对艾芙琳表现出同情——朱迪在观察你的反应。艾芙琳死后，选择："她不该落得如此下场"和"我很遗憾，朱迪。"

**两面**：艾芙琳葬礼后朱迪叫V到她公寓楼的屋顶。这是一场决定性的对话。选择："她对你很重要"和"你已经尽力了"。避免："她现在在更好的地方"（朱迪认为这很轻蔑）或"这只是一份工作"（这会锁定你）。

**前任因素**：舞子（朱迪的前任）提出从虎爪帮手中接管云顶。在云顶的对峙中，站在朱迪一边而非舞子一边。如果你接受舞子的钱或同意她的计划，朱迪的信任归零且恋爱被锁定。在云顶结果解决后，朱迪邀请V在湖边见面。

**金字塔之歌**：恋爱任务。朱迪带V去水肺潜水，前往她已被淹没的水库之下的童年小镇拉古那弯。潜水期间，朱迪分享她最私人的回忆。潜水后在控制室中，朱迪问："这对你是真实的，还是只是消遣？"选择："这是真实的。我们拥有的是真实的"以触发恋爱。其他任何选项（"只是消遣"或犹豫）永久锁定恋爱。

### 关系动态

确立关系后的朱迪是最投入感情的伴侣。她频繁发消息，从她的公寓发送自拍，并在她公寓的藏匿点中赠送V"莫克斯"霰弹枪。她是唯一一个明显搬进来的恋爱对象——"金字塔之歌"后她的物品出现在V的公寓中。如果V有多间公寓，朱迪对每间都有不同的评论。

### 结局条件

**星星**：如果恋爱且V选择阿德卡多结局，朱迪加入V和帕南一起上路。她离开夜之城——这被广泛认为是她的"好结局"，因为她从故事一开始就想离开这座城市。

**太阳**：朱迪给V留了一条结束关系的语音留言。她搬到了匹兹堡，已经结婚，并明确表示V是"美丽的一章，但已是已翻过的一章。"

**节制**：如果强尼获得身体，他的尾声展示他拜访朱迪告诉她V已经不在了。朱迪心碎但最终接受了。强尼给她留下一条消息说V爱过她。

**高塔**：朱迪已经完全向前迈进。她在匹兹堡结婚成家，礼貌但坚定地告诉V不要再联系她。

## 瑞弗·沃德（警探）

### 要求

| 条件 | 详情 |
|------|------|
| 体型 | 女性（女性声音和体型） |
| 声音 | 仅限女性V |
| 出身 | 任意 |
| 任务线 | 必须完成我对抗法律和狩猎 |
| 关键属性检定 | 无 |

### 任务链

**我对抗法律**：通过佩拉雷斯调查结识瑞弗。他正在调查莱恩市长的死亡并寻求V的帮助。在仓库的监视期间，瑞弗分享了他侄子兰迪的细节。选择支持性对话："你是个好叔叔，瑞弗。"

**狩猎**：恋爱任务。瑞弗请求V帮助调查他侄子兰迪的失踪。调查指向夜之城郊区的一处连环绑架犯农场。从农场救出兰迪后，瑞弗邀请V参加家庭晚餐。晚餐后，孩子们上床后，瑞弗和V坐在水塔上。选择："我想看看这会走到哪里"，然后亲吻他以触发恋爱。

**重要**：你必须在不可回头点（余烬）之前完成"狩猎"。如果你到达"夜曲Op.55 N.1"时仍未完成，该任务永久错失。

### 关系动态

瑞弗确立关系后的内容是所有人中最家庭化的。他邀请V到他的拖车参加家庭晚餐，发送关于乔丝和孩子们的短信，并在藏匿点中赠送V一把左轮手枪（"crash"）。与瑞弗的公寓互动很温馨——他做饭、弹吉他，搂着V入睡。他是"定下来"的选项，与强尼混乱的生活风格形成鲜明对比。

### 结局条件

**星星**：瑞弗支持但留在夜之城与他的家人在一起。语音留言是温暖的——他说当V从亚利桑那回来时他会等着。

**太阳**：瑞弗的语音留言是痛苦的。他说他无法一直等待一个总是追逐下一单的人。这实际上是一次分手。

**高塔**：瑞弗的命运是所有恋爱对象中最凄凉的。他入狱——被指控在警察生涯中腐败。他从监狱发给V的语音留言令人心碎。他说他不怪V，但他无法再做V记忆中的那个男人。

## 克里·欧罗迪恩（摇滚小子）

### 要求

| 条件 | 详情 |
|------|------|
| 体型 | 男性（男性声音和体型） |
| 声音 | 仅限男性V |
| 出身 | 任意 |
| 任务线 | 必须完成坚持住、第二次冲突、至尊之爱、叛逆！叛逆！以及船饮 |
| 关键属性检定 | 无 |

### 任务链

克里的任务线解锁较晚——在完成"磁带"（太平洲汽车旅馆场景）、"植入芯片"和"炽热之恋"之后。他是最容易被错过的恋爱对象，因为他的任务线嵌套在罗格和强尼的任务链之后。

**坚持住**：强尼请求V去探望克里。克里位于北橡区的豪宅遭到Us Cracks超级粉丝的破坏。清除破坏者后，在阳台上与克里交谈。选择："你还有那味，老兄"和"强尼说起过你。"

**第二次冲突**：帮助克里面对武士乐队剩下的原始成员。在会面时，站在克里一边反对想要卖出的乐队成员。

**至尊之爱**：武士重聚演出。在台上与克里一起演出。演出后在屋顶对话中，克里问V这场演出对他们意味着什么。选择："太不可思议了"和"你在台上炸裂了。"

**叛逆！叛逆！**：克里的中年危机任务。帮助他用燃烧弹发射器摧毁一辆Us Cracks巡演大巴。这个任务荒诞得令人捧腹——享受吧。

**船饮**：恋爱任务。克里邀请V登上他的游艇SEAWRAITH（海怒），停泊在海岸外。在甲板上的日落场景中，克里倾身靠近。选择："来吧"以亲吻他并触发恋爱。

### 关系动态

克里的恋爱关系是四个人中最随性和"摇滚"的。他发歌词短信，从录音室发自拍，并在藏匿点中赠送V一根镀金棒球棒。与克里的公寓拜访包括他弹吉他、喝酒、对他的人生遗产充满戏剧性。他更年长、有名、且对这段关系的荒诞性有自知之明——而这正是魅力所在。

### 结局条件

**星星**：克里的语音留言苦乐参半但支持。他说没有V夜之城将不再是同一个地方，但他能理解。

**太阳**：克里和V继续他们的关系。克里加入V的水晶宫劫案准备工作，最终场景暗示他们是夜之城精英圈中的一对强力情侣。

**高塔**：克里正在欧洲巡演。他的语音留言是疏远的——他已经转向一个更年轻的摇滚明星，更多将V当作一段美好回忆而非当前的伴侣。

## 约会与公寓机制

一旦恋爱关系激活，你可以邀请你的伴侣到V的任意公寓（原始沃森公寓、日本城公寓、公司广场公寓或峡谷区公寓）。每间公寓根据位置触发独特对话。与伴侣睡觉施加一个临时经验加成（随机技能+20%）持续60分钟游戏时间。

伴侣也会定期在V的藏匿点中留下礼物：
- 帕南："守望"狙击步枪、阿德卡多拉力波莱罗夹克
- 朱迪："莫克斯"霰弹枪、各种超梦花环
- 瑞弗："Crash"左轮手枪、NCPD徽章复制品
- 克里：镀金棒球棒、黑胶唱片

## 多线恋爱冲突

游戏允许你同时追求多段恋爱关系，但这会触发一场对峙。如果你同时与帕南和克里恋爱（男性V）或朱迪和瑞弗恋爱（女性V），你的伴侣们会在特定任务里程碑发现重叠并质问V。

男性V：克里在"船饮"期间发现帕南恋情并质问V。你必须选择其一——另一个永久锁定。

女性V：瑞弗在"狩猎"晚餐场景后发现朱迪恋情。朱迪在"金字塔之歌"后发现瑞弗恋情。两位伴侣都要求专一。选择其一永久锁定另一个。

没有同时维持两段恋爱关系的方法。游戏将同时追求视为背叛，被锁定的伴侣对话在剩余游戏中变得冷淡，但他们仍然可用于各自的任务完成。

## 每轮游玩最优恋爱路线

对于成就猎人：你可以在两轮完整游玩中恋爱全部四个角色（一次男性V，一次女性V），或从不可回头点起建立四个独立存档。

**单轮游玩效率**：男性V可以恋爱帕南和克里，如果你先完成帕南的任务线（"公路女王"在第二章早期触发恋爱），然后完成克里的任务线（在第二章末尾/第三章早期较晚解锁）。冲突场景在"船饮"期间触发——你可以在冲突点体验两段恋爱然后做出选择。

女性V可以对朱迪和瑞弗采取相同策略。先完成朱迪的任务线（"金字塔之歌"在"双鱼座"之后触发），然后完成瑞弗的（"狩猎"更早可用但"金字塔之歌"的时间安排灵活）。
